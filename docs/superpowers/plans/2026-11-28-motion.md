# Motion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the game feel alive at rest and in motion — drifting clouds, birds, motes, a shimmering sun, idle vehicle breathing, wheel roll and interaction feedback — at full frame rate.

**Architecture:** A pure `motionAt(time)` module turns the clock into a frame of offsets; `scene.ts` and the paint loop consume it. Vehicle motion is additive on top of the existing draw calls (`bob`, `spin`, `squash` options), and the paint loop switches from event-driven to continuous while the tab is visible.

**Tech Stack:** SvelteKit 3, Svelte 5, TypeScript, Canvas 2D, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-28-motion-and-more-pieces-design.md`

## Global Constraints

- No new dependencies.
- No image or SVG assets; all art is Canvas paths.
- `prefers-reduced-motion` must render a static world and static vehicle.
- Painting must stop when the document is hidden.
- Existing audio, settings lock, garage, scenes and job cutscenes must not change behaviour.
- All colours stay inside the existing palette and scene constants.

## Review Focus

- A backgrounded tab must not keep painting (battery).
- Reduced motion must not animate, including wheel spin and sparkles.
- A flipped rear wheel must roll the same visual direction as the front.
- Idle motion must never move drag anchors or the drop target.
- The perf test must still fail if painting never stops when it should.

### Task 1: Motion primitives

**Files:**
- Create: `src/lib/render/motion.ts`
- Test: `tests/unit/motion.test.ts`

**Interfaces:**
- Produces:
  - `export interface MotionFrame { time: number; cloudNear: number; cloudFar: number; sunAlpha: number; birds: { x: number; y: number; flap: number }[]; motes: { x: number; y: number; alpha: number }[] }`
  - `export function motionAt(timeMs: number, width: number, roadY: number): MotionFrame`
  - `export function wheelSpin(distance: number, radius: number, flip?: boolean): number`
  - `export const MOTION: { cloudNear: number; cloudFar: number; sunAlpha: number; birdPeriodMs: number; birdCrossMs: number; moteCount: number; maxWheelRadPerSec: number }`

- [ ] **Step 1: Write the failing test**

```ts
import { describe, expect, it } from 'vitest';
import { MOTION, motionAt, wheelSpin } from '#lib/render/motion';

describe('motion', () => {
	it('is deterministic for one timestamp', () => {
		const a = motionAt(12_345, 800, 640);
		const b = motionAt(12_345, 800, 640);
		expect(a).toEqual(b);
	});

	it('drifts clouds monotonically and keeps the far layer slower', () => {
		const a = motionAt(0, 800, 640);
		const b = motionAt(10_000, 800, 640);
		expect(b.cloudNear).toBeGreaterThan(a.cloudNear);
		expect(b.cloudNear - a.cloudNear).toBeGreaterThan(b.cloudFar - a.cloudFar);
	});

	it('sends a flock across once per period and never leaves the width', () => {
		const quiet = motionAt(1000, 800, 640);
		expect(quiet.birds).toHaveLength(0);
		const crossing = motionAt(MOTION.birdPeriodMs / 2, 800, 640);
		expect(crossing.birds.length).toBeGreaterThanOrEqual(3);
		for (const bird of crossing.birds) {
			expect(bird.x).toBeGreaterThanOrEqual(-40);
			expect(bird.x).toBeLessThanOrEqual(840);
		}
	});

	it('keeps a fixed number of motes above the road and inside the width', () => {
		const frame = motionAt(5000, 800, 640);
		expect(frame.motes).toHaveLength(MOTION.moteCount);
		for (const mote of frame.motes) {
			expect(mote.x).toBeGreaterThanOrEqual(0);
			expect(mote.x).toBeLessThan(800);
			expect(mote.y).toBeLessThan(640);
		}
	});

	it('caps wheel spin and reverses for a flipped wheel', () => {
		expect(wheelSpin(0, 30)).toBe(0);
		expect(wheelSpin(30, 0)).toBe(0);
		expect(wheelSpin(10_000, 30)).toBeLessThanOrEqual(MOTION.maxWheelRadPerSec);
		expect(wheelSpin(120, 30, true)).toBeCloseTo(-wheelSpin(120, 30), 6);
	});
});
```

- [ ] **Step 2: Run test to verify it fails**

Run: `pnpm vitest run tests/unit/motion.test.ts`
Expected: FAIL — cannot resolve `#lib/render/motion`.

- [ ] **Step 3: Implement `src/lib/render/motion.ts`**

Use `Math.sin`/`Math.cos` on `timeMs / 1000`. Constants: `cloudNear: 9`, `cloudFar: 3.5` (world units per second), `sunAlpha: 0.04`, `birdPeriodMs: 20_000`, `birdCrossMs: 7_000`, `moteCount: 5`, `maxWheelRadPerSec: 8`.
Birds active only in `[0, birdCrossMs)` of each period, starting at `x = -40` and moving to `width + 40`, `y` between `roadY * 0.18` and `roadY * 0.45`.
Motes wrap with `(base + time * speed) % width`.
`wheelSpin(distance, radius, flip)` returns `0` unless both are positive, else `clamp(distance / (radius * 2), -cap, cap)` signed by `flip`.

Run: `pnpm vitest run tests/unit/motion.test.ts`
Expected: PASS (5 tests).
